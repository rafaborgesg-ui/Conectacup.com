================================================================================
📖 POR QUE ACONTECE? (Explicação rápida)
================================================================================

O PROBLEMA:
  
  RLS Policies tentam fazer:
    SELECT FROM auth.users  ← ❌ Você não tem permissão!
  
  Supabase bloqueia usuários autenticados de acessar auth.users diretamente
  por segurança.

A SOLUÇÃO:

  Criar função com SECURITY DEFINER:
    public.is_user_admin()  ← ✅ Função TEM permissão!
  
  Policies usam a função ao invés de acessar auth.users diretamente.

✅ Você é administrador
✅ Tem acesso às páginas

================================================================================
📋 O QUE O FIX FAZ?
================================================================================

1️⃣ Cria função segura:
   CREATE FUNCTION is_user_admin()
   - Pode acessar auth.users (SECURITY DEFINER)
   - Verifica se você é admin
   - Retorna TRUE/FALSE

2️⃣ Atualiza policies:
   Antes: SELECT FROM auth.users  ❌
   Depois: is_user_admin() = true ✅

3️⃣ Aplica em:
   - Tabela geracao (gerações de carros)
   - Tabela chassis (chassis de carros)
